# Military Ready Raspberry Pi 
## *MRE-Pi*  

Securing a Raspberry Pi to Military Standards  

**Project Concept & Requirements:**  
1. [Follow a simplified Acquisition and Systems Engineering Process](https://www.linkedin.com/pulse/cybersecurity-process-integration-v-model-development-jadhav-dvnpc/)  
2. Focus is on Cybersecurity and not the Platform. The platform is tailored for a specific Cybersecurity use case.
   The goal is securing a Raspberry Pi.  The target operating system is PI OS which is a branch of Debian (as is Ubuntu).  The use case is to secure to military standards which can be significantly different from commercial standards.  The platform architecture has flexibility to become may things but this project will stay focused on Cybersecurity and not for example the many ways and versions you can install the Motion application.
4. The platform is to be a real-world platform not a rock sitting in a safe.
